## A. Samsung S24 Ultra, the debug APK

### Install and move the progress over

| # | Step | Expected |
| --- | --- | --- |
| A1 | In the web app (main site or a preview) save a progress file: "Ещё", "Данные", "Сохранить файл". | A file `chess-trainer-YYYY-MM-DD.json` in Downloads. |
| A2 | On the phone, download the artifact zip from GitHub (signed in), open it, open `app-debug.apk`. | Android asks to allow installs from this source once, then installs "Chess Trainer". |
| A3 | Open the app. | The same home screen as the web app, without the browser's address bar. No banner "Приложение готово к работе без интернета" (there is no service worker in the APK). "Ещё", "Диагностика": "Версия" 0.8.0, "Сборка" `m7 @`, "Режим запуска": an installed app or a browser tab (the WebView may report either; please note which). |
| A4 | "Ещё", "Данные", "Выбрать файл", choose the file from A1. | The system file picker opens; after choosing, "Файл от …" and "Заменить данные на устройстве". After confirming, the progress is there. |
| A5 | "Сохранить файл" in the APK. | The share sheet opens with a JSON file. Choose "Files" (Мои файлы) or Drive; the file is saved there. Closing the sheet without choosing saves nothing and shows nothing. |

### Notifications

| # | Step | Expected |
| --- | --- | --- |
| A6 | "Ещё", "Настройки". | A new block "Уведомления" with a switch "Напоминать каждый день" (off), and the calendar block below it. |
| A7 | Set the time two or three minutes ahead, then switch on. | Android 13+ asks for the notification permission now (not earlier). After "Allow" the switch stays on. If the app may not use exact alarms, a line says the reminder may come up to an hour late, with "Разрешить точное время". |
| A8 | Press "Разрешить точное время". | The system screen "Alarms & reminders" for the app opens; allow it and come back; the line disappears. |
| A9 | Leave the app and wait for the time. | One notification "Chess Trainer" with a short friendly text. Tapping it opens the app. |
| A10 | Do one exercise today, then look at the pending reminder. | No reminder today once the norm is met (it was cancelled); tomorrow's is still there. Checking this needs either waiting until tomorrow or a reminder time later today. |
| A11 | Reboot the phone and wait for the next reminder time (do not open the app). | It still comes: the plugin restores reminders after a reboot. **Not checked; Samsung may delay it.** |
| A12 | Switch the permission off in Android settings, open the app, "Настройки". | "Уведомления запрещены в настройках телефона…" The app works as before; the calendar option is still there. |
| A13 | Phone idle for hours (Doze), e.g. a reminder in the morning after a night on the table. | It comes, possibly a few minutes late. Please note how late. |
